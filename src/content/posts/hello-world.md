欢迎来到 **Amsors' Blog**。

这个站点基于 Astro 和 Fuwari 构建，文章以 Markdown 文件保存在 GitHub 仓库中。每次把新内容推送到 `main` 分支，Cloudflare Pages 都会自动构建并发布。

## 这里会有什么

我会把值得留下的实践、问题和思考写在这里。一篇文章不一定很长，但希望它是准确、可复现，也对未来的自己有用的。

:::tip
可以通过顶部的归档、标签和搜索功能浏览内容，也可以订阅 `/rss.xml` 获取更新。
:::

## 技术组成

- Astro 负责静态站点生成
- Fuwari 提供主题、响应式布局、搜索和 RSS
- GitHub 负责版本管理
- Cloudflare Pages 负责全球分发和持续部署

新的记录，从这里开始。
